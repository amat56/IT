# MyUnit Calendar Android

Android WebView wrapper untuk demo standalone MyUnit Calendar.

## Cara bina dalam Android Studio
1. Buka folder ini dalam Android Studio.
2. Tunggu Gradle Sync selesai.
3. Pilih **Build > Build App Bundles or APKs > Build APK(s)**.
4. APK akan berada di `app/build/outputs/apk/debug/app-debug.apk`.

## GitHub Actions
Push folder ini ke GitHub, kemudian buka **Actions > Build APK > Run workflow**. APK debug akan tersedia sebagai artifact.
